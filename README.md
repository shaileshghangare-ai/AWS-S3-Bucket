# AWS-S3-Bucket

## Introduction

Amazon S3 (Simple Storage Service) is a cloud storage service provided by Amazon Web Services (AWS). It allows users to store, retrieve, and manage data over the internet.

An S3 bucket is a container used to store files such as images, videos, documents, backup files, log files, and cybersecurity reports.

## AWS S3 practical using the AWS Console

* Sign in to the AWS Management Console.
* Search for S3.
* Click Create bucket.
* Enter a globally unique bucket name.
* Select your AWS Region.
* Keep Block all public access enabled.
* Click Create bucket.
* Open the bucket and select Upload to upload a file.
